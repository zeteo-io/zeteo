Google Sheets sources: a user with `zeteo.uploads.write` adds a spreadsheet shared with Zeteo's Google service account and gets a `google-sheets` upload source that syncs every 15 to 1440 minutes (default 60) or on Sync now. An admin saves the service-account key under Connections (`GET` and `PUT /v1/connections/google`, sealed, checked with Google before saving). `POST /v1/uploads/links` previews a sheet like a file. One spreadsheet backs one unarchived source (`sheet_in_use`). Values load with Sheets' types and number formats in the sheet's time zone. A sync matches columns by header text and tabs by sheet id, keeps the last good data when it fails and records `last_error` for the owner; a source shows Stale after 24 hours of failures. New error codes: `invalid_sheet_link`, `sheet_in_use`, `sheet_not_accessible`, `google_not_configured`, `google_key_rejected`, `google_unavailable`, `google_sign_in_failed`, `staging_kind_mismatch`, `tab_already_added`, `not_a_file_upload`, `not_synced`, `not_a_sheets_source`, `sync_too_soon`. The header-row suggestion changes for CSV and xlsx files too: a label row under a sparse banner is now suggested as the header. UI: Connections, a Google Sheet choice in Add data, Sync now. SDK: the Google connection and sheet-link calls and the Sheets source fields. BREAKING: the catalogue's `last_synced_at` is now `last_loaded_at`, and so are MCP `list_tables`' and `describe_table`'s; a file upload's owner calling `POST /v1/sources/:id/refresh` now gets `409 not_a_database_source` instead of `403`; `POST /v1/sources/:id/refresh` may return a `SyncSummary` and is `429 sync_too_soon` within a minute on a Sheets source; the refresh job now checks every 5 minutes.

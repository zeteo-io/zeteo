Google Sheets and merged tables in upload sources. There is one upload source type, `upload`, and each table has an origin: a file, a Google spreadsheet tab (with its spreadsheet, tab id and tab title) or a merged table, so one source mixes them. Add data and Add tables take a file or any spreadsheet link (`POST /v1/uploads/links` with `{ url }` or `{ source_id, url }`); re-upload is for file tables only. An admin saves the Google service-account key under Connections (`GET` and `PUT /v1/connections/google`, sealed, checked with Google before saving). First claim wins per spreadsheet: it backs tables in at most one source, claimed when a source first gains one of its tabs and released when the source is deleted or its last non-removed table of it is removed (`sheet_in_use`, which never names the owner). Sheets tables sync on one interval per source (15 to 1440 minutes, default 60) or on Sync now (`POST /v1/sources/:id/refresh`, once a minute); each table loads in its own transaction, so one failure never holds back the others, and a failed table keeps its last good data and records `sync_error` for the owner. A source shows `sync` (`interval_minutes`, `last_attempt_at`, `failing`, `stale`), and tab titles refresh on sync. Merged tables (`POST /v1/sources/:id/merged-tables`, `PUT .../tables/:tableId/merged`, `GET .../merged-tables/columns`) stack two or more tables of a source as a live view with a label column, per-member labels, a chosen union of columns (disagreeing types become text, a missing column is NULL), warnings for members that go missing, and their own grants. Values load with Sheets' types and number formats in the sheet's time zone. New error codes: `invalid_sheet_link`, `sheet_in_use`, `sheet_not_accessible`, `google_not_configured`, `google_key_rejected`, `google_unavailable`, `google_sign_in_failed`, `staging_kind_mismatch`, `tab_already_added`, `not_a_file_upload`, `not_synced`, `not_a_sheets_source`, `sync_too_soon`, `nothing_to_sync`, `table_in_merged_table`. The header-row suggestion changes for CSV and xlsx files too: a label row under a sparse banner is now suggested as the header. UI: Connections, an Origin column, Add tables from a file or any sheet, Add merged table and its editor, a Sync failing badge, Sync now (only for a source with Sheets tables). SDK: the Google connection, sheet-link, merged-table calls and the origin and sync fields. BREAKING: the catalogue's `last_synced_at` is now `last_loaded_at`, and so are MCP `list_tables`' and `describe_table`'s; a file upload's owner calling `POST /v1/sources/:id/refresh` now gets `409 nothing_to_sync` instead of `403` when the source has no Sheets table; `POST /v1/sources/:id/refresh` may return a `SyncSummary` and is `429 sync_too_soon` within a minute; the refresh job now checks every 5 minutes.

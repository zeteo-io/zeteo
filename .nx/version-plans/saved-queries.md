Saved queries: a user keeps a query under a name, runs and exports it, shares it with users and groups, copies it and transfers it, and a recipient runs it with their own grants only. `/v1/saved-queries`, `GET /v1/me/runs`, `GET /v1/me/principals`, the permissions `zeteo.saved_queries.read` and `.write`, MCP tools for saved queries, "My Zeteo" and a Saved queries section in the admin UI. SDK: `savedQueries` and `me.runs` calls.

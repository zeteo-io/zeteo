The MCP tool `preview_panel` takes either `saved_query_id` or `query` (the `query` tool's JSON, run exactly as that tool runs it, with nothing saved), so a model can show a chart, and the preview card under the call, without saving a query first; `card_panel_rows` takes `query` too. The instructions, the tool descriptions and the plugin's dashboards skill now say to preview with `query` and save only when the person wants to keep the chart. The Claude Code plugin is 0.2.1.
